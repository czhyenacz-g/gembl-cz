# public/audio/sfx/

Sem patří reálné soubory herních zvukových efektů (viz `lib/audio/sfx.ts`
a `docs/audio-assets.md`). Prázdné dokud sem někdo ručně nevloží legálně
podložené MP3 soubory — do té doby zůstávají v `sfx.ts` jen placeholder
záznamy a `playSfx()` tiše nic nepřehraje (soubor prostě chybí, nic nespadne).
